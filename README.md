# AI Skills · 把常用任务整理成可复用流程

这个仓库收录我整理的 4 个 AI 工作流程，覆盖竞品研究、中文写作、英语口语学习和个人资产配置分析。每个目录用 `SKILL.md` 定义任务入口、处理步骤、交付形式和质量要求；需要更细说明时，再配合参考材料、模板或脚本。

我关注的是一次任务怎样从模糊输入走到清楚的交付，以及资料不全、用户目标变化或结果需要复核时，流程怎样继续。

## 输入示例

以下是可以交给支持 Skill 的智能体的任务示例，未附模拟运行结果。

**竞品研究**

> 我想做面向国内小型宠物医院的 Web 管理工具，优先解决预约、病历和回访。先帮我明确竞品范围，再比较代表产品的功能、价格和使用流程。

**中文写作**

> 根据我提供的来源和草稿，写一篇面向普通读者的产品观察。保留能核实的细节，区分事实与推断，并给出配图位置。

**英语口语**

> “I'm on the fence” 在口语里怎么用？先中英结合解释，再和我练一段周末出行的对话，一次问我一句。

**资产配置**

> 我会提供本月收支、现金储备、应急金目标、未来支出和各类资产余额。先检查资料是否齐全，再整理当前比例与新增资金分配方案。

## 几个具体设计

- **任务范围先清楚。** 竞品研究区分直接竞品、间接竞品和替代方案，也区分使用者与付费者。
- **生成内容保留依据。** 研究和写作流程要求核对来源、时间与口径，资料不足时缩小结论范围。
- **让用户继续参与。** 英语学习一次只推进一轮，根据回答纠错，并允许在对话与拓展路线之间切换。
- **把能检查的规则写成工具。** 中文检查器会定位禁用表达、重复句式等问题，并将确定的规则错误与需要人工判断的警告分开。

## 使用条件与当前范围

使用这些流程需要能够读取 `SKILL.md` 的智能体环境。根据任务，还需要联网检索、浏览网页或处理文件等相应能力；仓库本身没有提供模型服务和联网服务。

中文文本检查器是 Python 脚本，可读取 Markdown、纯文本文件或标准输入。它用于检查预设写作规则，不能验证事实，也不能判断文章是否由 AI 创作。

资产配置部分目前提供方法与模板，**当前目录未包含独立自动计算脚本**。其子目录文档引用的 `scripts/rebalance.py` 尚未收录；输入模板和示例输出也只用于说明结构，实际分析仍需补齐主指令要求的数据。

英语学习流程也以独立仓库维护；本仓库的 `learn-spoken-english/` 收录同源版本。以上内容适合查看任务设计与实现方式，仓库尚未附完整运行评测记录。
